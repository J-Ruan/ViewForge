# 几何算法与误差

## 输入约束

每个视图的顶点保存在归一化图纸坐标中，向右为 u 正方向、向上为 v 正方向。自动尺寸关联和分段标定（或手动设置）后，实际尺寸与偏移再转换为 mm。导入 SVG/位图时翻转屏幕 Y，DXF 保持数学 Y。识别以零件边界建立局部原点；外部标注不再扩大实体边界。标注驱动的分段映射将邻近的轮廓顶点吸附到尺寸界线，恢复精确分段尺寸。详见 RECOGNITION.md。

闭合路径隐含最后一点与第一点的边，不要求重复首点。删除连续重复点；拒绝少于三点、零面积、非有限值、自相交、非相邻边相触。多环允许完全包含或分离，拒绝互相穿越/相触。奇偶填充支持外环、内孔、孔中孤岛和不相交实体。

## 反投影

front=(X,Z)，top=(X,Y)，side=(Y,Z)。轴映射由列主序矩阵定义，投影使用它的逆映射。侧视方向与用户镜像仅在二维校准阶段处理。

每个视图对两个轴给出有限区间；未约束轴由另一视图确定。公共轴区间必须有正长度。每个区域沿其法向轴拉伸，得到 E₁、E₂，候选 M=E₁∩E₂。Manifold 处理反射矩阵、非凸截面、内孔和实体交集。交集的非空性、内核 status、体积与包围盒都来自内核，未预设网格或体积。

必要但不充分的公共轴重叠不能保证相容，因此继续将 M 正交投影到两个平面。对每一投影 P 和输入区域 S，计算 IoU=area(S∩P)/area(S∪P)。数字几何基础候选任一 IoU<0.999 拒绝生成。位图另检查空间边界容差：若输入和投影的双向差异均包含在按像素分辨率估计、且不超过最小尺寸 1% 的偏移区域内，作为轻微扫描差异允许生成并明确提示；不改写实际 IoU。超出该范围仍拒绝生成。坐标单位为 mm，曲线采用离散折线。

若相容，M 是符合这些轮廓的最大实体，但空腔、遮挡面、局部凹陷仍可能有无穷多个解释。后续人工特征不参与“从视图推断”，而是在 M 上明确执行布尔差集。切除后的投影重新计算，可以出现偏差；叠加图展示 S\P（红）和 P\S（橙）。内部棱线、隐藏线不在本版验证范围，不能以 IoU 当成真实正确率。

## 切除特征

圆柱：起点为底面圆心；矩形：起点为底面左下角。沿 +X 时截面为 YZ，沿 +Y 为 XZ，沿 +Z 为 XY。圆柱固定 96 段多边形逼近，体积按实际多边形而非理想 πr²h 计算。矩形孔、凹槽和基础块切除共享一个显式长方体工具，不自行猜测贯穿深度。切除未相交或全部移除模型时报告错误，不输出陈旧结果。

## 稳定性

所有 WASM 对象在 finally 中逆序 delete。Worker 将网格数组转移主线程，30 秒超时或新任务终止旧 Worker。Three.js 场景清理几何、材质、控制器、观察器、动画与渲染上下文资源。资源限制避免常见大图失控；不能代替恶意输入的完整计算预算隔离。
